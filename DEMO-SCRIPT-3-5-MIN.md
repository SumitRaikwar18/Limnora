# Limnora demo script

Target length: 3:30-4:15.

## 0:00-0:25 - Problem

Citizen observations can be valuable, but a photo and a guess should not become a water-health conclusion.

## 0:25-0:50 - Product thesis

Limnora is an evidence-assurance layer for freshwater citizen science. It turns uncertain observations into traceable evidence, human review and targeted revisit questions.

## 0:50-1:25 - Real observation

Show the map, select a mapped or declared freshwater body, add field context and upload a permissioned original field photo. Make clear that the original observer label is preserved.

## 1:25-2:10 - Signature moment

Open AI screening. Explain that the AI did not receive the observer category. Show visible evidence, alternatives, uncertainty and disagreement if it genuinely exists.

## 2:10-2:45 - Human judgment

Save or show a human review. Explain that the original label remains unchanged and review events are additive.

## 2:45-3:15 - Revisit

Show the targeted next observation. If a genuine linked revisit exists, compare it. If not, say the revisit is pending and do not invent completed field work.

## 3:15-3:40 - Evidence handoff

Show the water-body timeline and export. Mention Limnora JSON and FHIR interoperability prototype.

## 3:40-4:05 - Architecture and safety

Show README architecture. State that AI supports evidence collection; it does not certify water safety.

## 4:05-4:20 - Close

Limnora turns disagreement into better data.
